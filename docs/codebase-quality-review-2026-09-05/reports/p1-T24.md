# T24 — deploy/ units, nginx, and platform config (109 files, 8,971 lines)

## A. Tile mandate & verdict

**Mandate:** the declarative half of the runtime — what systemd starts, as whom, with what
restart/hardening policy; what nginx routes; what ALSA/tmpfiles/polkit/udev/sysctl the platform
needs before any JTS process runs.

**Verdict: one system, but with no single owner per fact and no single install path.** The units
themselves are coherent (consistent OOM ladder −950…−300, consistent FIFO ordering 25<30<35,
consistent slice/ring/UMask discipline). Three seams are tangled:
(1) **two install paths** — `install_systemd_units` (full) re-inlines line-for-line what
`install_streambox_systemd_units` reaches through six extracted helpers;
(2) **two nginx confs** whose non-comment content is 94 % identical but where only one carries the
rationale;
(3) **every operational fact — port, socket path, unit roster, derived timeout — is spelled in
3–6 places** and held together by ~7,600 lines of source-text-asserting tests instead of by one owner.
The tile is **43 % comment lines** (3,874); several files are 90 % essay, 10 % config.

**Units nothing installs: none.** Every unit file has an install path (12 go through
`JASPER_CORE_AUDIO_GRAPH_INSTALL_ROWS`, `systemd-units.sh:77-99`). Every unit with `[Install]`
that is never `enable`d has a verified on-demand starter (`restart_broker.MANAGED_UNITS`/
`START_ONLY_UNITS`, a `.path`, a `.timer`, udev `SYSTEMD_WANTS`, or `OnFailure=`).

**Reboot-escalation policy (`StartLimitAction=reboot`), 5 units:** fanin (300/5), outputd (300/5),
control (300/4), voice (300/20), aec-bridge (300/4). Cross-boot circuit breaker:
`jasper-bootloop-guard.service` writes `/run` drop-ins setting `StartLimitAction=none`, discovering
guarded units by grepping `/etc/systemd/system` — so the `Before=` list at
`jasper-bootloop-guard.service:20-21` is decoration, correctly noted. Incident/ADR ties exist for
all five (ADR-0146 T5.1; ADR-0141 for outputd's park-instead-of-reboot; ADR-0175 for camilla's
deliberate `StartLimitAction=none` + `jasper-camilla-recover`) **but no unit names its ADR** — the
units carry the full narrative and the pointer is missing (AGENTS.md asks for the pointer, not the
narrative). aec-bridge's reboot risk is already logged as ADR-0235 G13 (in flight, #4027).
