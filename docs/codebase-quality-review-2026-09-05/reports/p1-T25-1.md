# Tile T25-deploy-assets-1 — 38 files, 15,509 lines

## A. Tile mandate & verdict

This tile is half of `deploy/assets`: the static JS/CSS for the jts.local management UI (nginx-served, no build step). It is **two eras of the same system, not one**: (1) a shared design/behaviour layer (`app.css`, `shared/js/*`) that is genuinely single-source-of-truth and well-factored; (2) page bundles split cleanly between a **post-#4031 generation** (`system-status/*`, `chat/views.js`, `rooms/pair-balance-controller.js`, `correction/crossover/chart.js`, `wake-corpus/controls.js`) built on `dom.js`'s `h()`/`svg()`, dependency-injected, unit-tested — and a **pre-#4031 generation** (`wifi/main.js`, `sound-profile/main.js`, `tools/render.js`) still hand-rolling `innerHTML` string concatenation, which `docs/web-ia.md` §3 explicitly says not to do. Both generations correctly use the shared CSRF/dialog/escape modules, so the boundary layer held; what's left of #4031 is finishing the innerHTML→dom.js migration and mopping up small pockets of pre-shared-module duplication (clipboard copy, JSON POST, render-memoization) that predate `shared/js/*` and were never converged onto it.
