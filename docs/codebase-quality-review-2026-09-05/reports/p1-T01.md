# T01 — voice loop (`jasper/voice_daemon.py` + `jasper/voice/`)

SHA 2d571e6b8. 18 files, 14,745 LOC.

## A. Tile mandate & verdict

**Mandate:** own the wake→turn→TTS lifecycle for one speaker, and adapt three
realtime LLM providers to one provider-neutral turn contract.

**Verdict: three tangled systems, not one.** (1) a clean provider layer
(`session.py` protocol + `_supervisor.py` + three adapters) that is ~70 %
converged and knows what it is; (2) `WakeLoop` — a 4,528-LOC / 96-method god
class holding wake detection, turn lifecycle, cue playout, research
announcements, conversation persistence, peering IPC, barge-in, telemetry and
an entire **room-correction measurement-window state machine** that has nothing
to do with voice; (3) `daemon_main.run()` — a 643-LOC composition root wiring
~25 subsystems. The file hierarchy actively misleads: `jasper/voice_daemon.py`
is *not* the daemon (that's `voice/daemon_main.py`), yet it holds the entry
point via three delegating shims and imports `daemon_main` inside function
bodies to dodge the cycle `daemon_main` creates by importing it back.
