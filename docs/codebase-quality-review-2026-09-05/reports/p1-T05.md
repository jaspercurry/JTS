# T05 — DSP control (camilla / sound emission / fan-in ring). SHA 2d571e6b8

## A. Tile mandate and verdict

**Mandate:** own the CamillaDSP control plane end-to-end — the websocket client and the
fader clamp (`camilla.py`), the YAML *format* and *contract* leaves (`camilla_emit`,
`camilla_config_contract`, `camilla_stereo_prefix`), the program-domain emitter and its
carrier dispatch (`sound/`), the validate→load→confirm→rollback transaction (`dsp_apply`),
and the SHM-ring transport this all rides (`fanin_coupling`, `fanin/`, `ring_assets`).

**Verdict: three systems, only loosely tangled — and the seams are already right.**
`camilla*.py` + `sound/` is one coherent stack with a clean leaf→assembly→carrier layering.
`fanin/` + `fanin_coupling` + `ring_assets` is a second, self-consistent one (vocabulary /
proof / convergence, one-way dependency, documented). `dsp_apply` is the shared writer
boundary both use and is correctly neutral. What is wrong is not the decomposition — it is
**38% prose (5,854 of 15,446 lines)**, 16 functions over 100 code-LOC, and three files
(`coupling_reconcile`, `ring_assets`, `fanin_coupling`) that have outgrown their names.
`dsp_numpy.py` is the one file with no business in this tile at all.

## NON-NEGOTIABLE 1 — verdict: **UPHELD at every emitter and at the durable apply path;
one unguarded live door.**

**Clamp (`set_volume_db`).** `camilla.py:139-161` `_coerce_main_volume_db` clamps to
`MAX_MAIN_VOLUME_DB = DEFAULT_VOLUME_LIMIT_DB = 0.0`, rejects non-finite/non-numeric, and is

`set_main_volume` writers in the tree. `declare_main_volume_db` (`:1128`) routes through

**Is config emission one-owner? Yes for the *ceiling*, no for the *template*.** All seven
emitters funnel their limit through one `ensure_volume_limit_db` (`camilla_config_contract.py:438`)
— that fact has exactly one home. But there are **seven hand-written YAML templates** (one
stereo + six active), and only the leaf *lines* (`camilla_emit`) and the program prefix
(`camilla_stereo_prefix`) are shared; the `devices:` block is retyped seven times. That is
the real single-source-of-truth gap, and it is what makes a seventh emitter a real risk.

**The gap (Should-fix, not a live defect).** `CamillaController.set_active_config_raw`
(`camilla.py:900`) uploads arbitrary YAML with **no** `volume_limit` check, and
`patch_config` (`camilla.py:1000`) forwards an arbitrary mapping. ~10 production callers;
every one today feeds emitter-produced text, so the invariant holds *by caller convention*.
The `/sound/live-draft` slider path (`web/sound_setup.py:1406`) uses this door on every
interaction and never reaches `apply_dsp_config`, so it is the one write to the running
graph with no independent ceiling check. Fix is three lines — see finding 1.
