## A. Tile mandate and verdict

**Mandate:** serve the stdlib-HTTP wizard pages behind nginx — route, read/write one
wizard-owned env file, render one page, hand mutations to a seam.

**It is two systems, not one.** Ten files (transit / weather / tools / sources / airplay /
home-assistant / wake-corpus + the three `correction_*_flow`/`hub` templates) are that
system, and they are broadly healthy: 8–28 % prose, `_common.py` adopted, mutations via
`manage_units`/`restart_voice_daemon`, no direct systemctl writes. The eleventh file,
`correction_crossover_v2.py`, is **48 % of the tile's lines and is not a web page at all**:
zero routes, zero HTML, zero CSRF, no `BaseHTTPRequestHandler`. It is the crossover-v2
conductor host — durable state, a volume-plan singleton, seam bindings, the apply
transaction — parked under `jasper/web/` and reached only through `correction_setup`'s
dispatch. Everything in section C's top third is about that file.

**Premise correction for the brief:** at this SHA there is no `_make_handler` in
`correction_crossover_v2.py`. The 994-LOC / 33-local-import `_make_handler` is
`correction_setup.py:3902` (tile T16-web-3); `sound_setup.py:4702` is 741 (tile T16-web-2).
Both measure CC 1 — they only define a class and return it; complexity lives in the nested
`Handler` methods. The repo's most complex web functions are in **this** tile:
`_post_apply_grade` (CC 66), `handle_v2_apply` (CC 66), `prepare_v2_session` (CC 57).
