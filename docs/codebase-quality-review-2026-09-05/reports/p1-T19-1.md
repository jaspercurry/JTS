## A. Tile mandate & verdict

**Mandate:** own the fan-in work loop — read N capture lanes (aloop / renderer SHM ring / USB
gadget), sum them at one resolved numeric width, duck for TTS, publish to Ring A — and the
config that sizes it.

**Verdict: one coherent system with two passengers.** The read→sum→duck→publish spine
(mixer.rs, dsp.rs, lane_fade.rs, pcm_open.rs, ring_capture.rs) is genuinely one machine and
reads that way. The passengers are `impulse_tap.rs` (a lab latency harness, 1,327 lines living
inside an RT daemon) and `config.rs` (a 573-LOC `from_env` god function). `mixer.rs`'s
`mod dsp/pcm_open/ring_capture/direct_capture` split moved code but not the boundary — every
submodule opens with `use super::*` and reaches `Input`'s private fields, so the parent is still
3,039 production lines and no submodule has an interface.
