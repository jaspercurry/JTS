# T18 — jasper/ platform primitives + the top-level remainder (59 files, 9,309 LOC)

## A. Mandate and verdict

Nominal mandate: *the leaf primitives every other package consumes* — atomic file
publication, env-file parsing, structured logging, systemd reading, HTTP guards, JSON
field coercion — plus speaker identity and the process/OS scaffolding.

**Verdict: not one system. It is four tangled ones plus a dumping ground.**
(1) a genuine, well-built platform layer (`atomic_io`, `log_event`, `env_load`,
`json_fields`, `http_security`, `backoff`, `busctl`, `transition_log`);
(2) an identity/network stack (`identity*`, `speaker_name*`, `mdns`, `avahi_service`,
`control_advert`, `usb_network`, `usbgadget`, `wifi_*`);
(3) a wake/audio-input cluster that has no business at this altitude (`wake*`, `vad`,
`openwakeword_guard`, `audio_buffer`, `aec_ready`);
(4) `config.py` — a 1,020-line re-declaration layer over state that other modules
already own.
The residue (`spotify_uri`, `citibike`-adjacent leaves, `airplay_mode`, `audio_lab`,
`percentiles`, `os_fault`) is there because `jasper/` top level is where a file goes
when nobody decided. **116 top-level modules is the finding**, not a symptom.

Prose share of the tile: **34 %** (2,123 docstring + 1,013 comment lines / 9,260).

## §3. `config.py` — the natural split

`from_env` is `461-958` = **498 LOC**; `_validate` is 81. But the body is one
`return _validate(cls(...))` with ~94 keyword arguments and **~250 interleaved comment
lines** — decomposing it into helper functions would just move the prose. The split
that pays, in order:

1. **Finish the Pattern-2 migration the file already documents.** `config.py:393-396`
   and `:889-891` say transit moved to per-provider `build_client(env)` self-parse, and
   `:443-444` says research providers did too. The four remaining integration blocks are
   the same shape and should follow their owners: **spotify** (6 fields → `accounts.py`
   / `spotify_router`), **google** (5 → `google_creds`), **home_assistant** (4 → `home_assistant.py`,
   which already owns `ENV_URL/ENV_TOKEN/…`), **weather** (5 → `weather.py`, taking the
   `JASPER_TRANSIT_LAT` fallback at `:497-513` with it). ≈ 20 fields, ≈ 130 LOC out.
2. **Stop re-declaring paths other modules own.** `librespot_state_path`,
   `volume_state_path`, `assistant_loudness_profile_path`, `usage_db`,
   `mic_mute_state_path`, `timer_db_path`, `sounds_dir`, `wake_events_dir`,
   `peering_uds_socket` (whose comment at `:950-954` admits it duplicates
   `peering.config.PEERING_UDS_PATH` "so voice_daemon doesn't have to import the peering
   package"). Each already has an owner module with a `DEFAULT_PATH`; consumers should
   ask the owner. ≈ 9 fields.
3. **What's left is `VoiceConfig`** (~40 fields: provider, keys, models, voices, VAD,
   timeouts, spend cap) — move the whole dataclass to `jasper/voice/config.py`, which is
   where every one of its readers lives. `jasper/config.py` then holds `hostname`,
   `management_url`, `camilla_*`, `duck_*`, `tts_*` and the mic/wake block: **≈ 250 LOC**.
4. Move the per-field essays (model pricing history, OpenAI session-cap rationale, the
   `tts_drain_tail_sec` measurement) to an ADR. That is the other ~250 lines.

Ordering matters: do (1) first — it is mechanical, has precedent in-tree, and shrinks
the god function by a quarter with no new abstraction.
