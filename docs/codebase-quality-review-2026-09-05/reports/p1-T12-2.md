## A. Mandate and verdict

**Stated mandate** (`__init__.py:5-18`): "shared acoustic-measurement kernel —
measurement primitives and shared filter maths every JTS tuning layer reuses…
This package imports no feature layer." The no-upward-import half is TRUE and
pinned (`tests/test_correction_boundary_ssot.py`); grep found zero
`jasper.active_speaker` / `jasper.correction` imports, only 18 docstring
references.

**Verdict: four tangled systems under one package name, not one kernel.**

| system | files in my half | is it "shared filter maths"? |
|---|---|---|
| DSP kernel | analysis, sweep, gating, alignment, frame_fit, olive_metrics, peq, quality, quality_model, snr_policy, spatial_combine, timeline_slip, excitation | yes — the mandate |
| Phase analysis engine | `program_analysis/*` (2,567 LOC in my half) | yes, but it is an *engine*, not a primitive |
| Admission / authority / async playback | admitted_playback (654) + sibling's playback/excitation_admission/excitation_artifacts/evidence_identity (~140 KB) | **no** — asyncio, ALSA devices, one-shot artifacts, household copy |
| Persistence & vendor I/O | calibration (HTTP scraping of daytonaudio.com + minidsp.com, `urllib`), bundles (manifest store), measurement_geometry (`/var/lib/jasper` writer) | **no** |

A newcomer asked "where does a vendor website scraper live?" would not guess
`audio_measurement`. The admission cluster and the calibration/bundles cluster
each have a coherent mandate of their own; neither is the one on the tin.
