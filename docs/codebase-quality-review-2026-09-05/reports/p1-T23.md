# T23 — deploy/install.sh + deploy/lib/**  (22 files, 9,206 lines)

## A. Tile mandate & verdict

**Mandate:** the one deploy path (non-negotiable 4) — put a verified build of JTS on a Pi,
idempotently, on either install profile, without killing a live speaker while doing it.

**Verdict: one system, forked down the middle.** `install.sh` + `lib/install/*` is a single
coherent installer with genuinely good containment (`build-sandbox.sh`), a real rollback domain
(`_transactional_full_unit_install`), and a real success-marker contract (`write_build_manifest`,
ADR-0172). But **the full/streambox profile fork is expressed by copy, not by data**: two 40-line
`main()` sequences, 12 `*_streambox_*` twins, 365 lines of hand-written dry-run prose in two
heredocs, and a 202-line test whose only job is keeping the prose in sync with the code. Nine of
the 15 findings below are downstream of that one decision. `deploy/lib/*.sh` (the runtime-shared
fragments) is a *second, healthier* system that happens to live in the same directory.
