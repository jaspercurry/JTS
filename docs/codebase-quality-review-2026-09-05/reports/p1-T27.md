## A. Tile mandate

One coherent system: **how a change gets validated and released** — CI lane
routing, the Python/Rust/JS/shell gates, dependency-update policy, editor/agent
config, and the one alternate release artifact (pre-built ARM64 runtime bundle
for the constrained Pi Zero 2 W path). Genuinely one system, well-factored
internally; the friction is duplication *within* `tests.yml` and across the
handful of files that each name the same Rust crate roster.
