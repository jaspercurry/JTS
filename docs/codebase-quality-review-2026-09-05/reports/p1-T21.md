# T21 — rust/ shared crates (jasper-clock, -host-clock, -ring, -resampler, -tts-protocol, -env)

## A. Tile mandate & verdict

**Mandate:** the pure, host-buildable primitives the two ALSA daemons (jasper-fanin,
jasper-outputd) and the C ioplug share — one clock loop, one resampler, one SHM ring
format, one TTS wire + loudness policy, one env parser.

**Verdict: not one system — three, plus two strays.**
1. **A genuine shared core** (jasper-clock, jasper-resampler, jasper-ring, jasper-tts-protocol):
   real multi-consumer primitives, correct mandate, over-documented.
2. **A single-consumer device driver misfiled as shared** (jasper-host-clock, 3,804 LOC):
   one consumer (jasper-fanin), one `ObsMode` variant, and a `jasper-clock` dependency
   whose `Dll` is **never ticked**. It was factored out for a second daemon that never came.
3. **A crate that is really a workspace bug** (jasper-env, 60 LOC of code): carries a
   Cargo.toml, a Cargo.lock, a CI step, a rust-cache entry, a dependabot entry, a
   check-rust.sh entry, and a deploy staging block — to share four functions.

Cross-cutting: **eight crates, eight lockfiles, eight CI steps, and the crate list spelled
in five places** — the strongest single lever in this tile (finding 1).

**Earns-its-keep (tried to cut, could not):**
- `jasper-clock` as a separate crate: 3 real consumers (jasper-resampler, jasper-outputd/dac_clock, and — nominally — jasper-host-clock), pure, host-testable, ~250 code lines. Correct factoring. Merging it into jasper-resampler would make jasper-outputd link a resampler to get a loop.
- `RingWriter::publish(&[i16])`, the "wrapper [that] goes away with the last of them": jasper-fanin/src/mixer.rs:2024 still uses it for the narrow ring wire. Keep.
- The Rust/Python K-weighting duplication (loudness.rs:27-39 vs `jasper/assistant_loudness.py:46-60`): different jobs (allocation-free live rolling windows vs numpy offline gated LUFS) and genuinely pinned by a shared golden — `bs1770_impulse_matches_cross_language_golden` (loudness.rs) ↔ `tests/test_assistant_loudness.py:41-48` assert the same `-48.243146…`. Not a duplicate to merge.
- `jasper-ring`'s golden-layout test + the C `_Static_assert`s: both sides pin independent literals, so either side drifting fails its own build. Correct design.
