# Instrument-error catalog

> WO-0 deliverable 2 of the attribution-stage plan, §7.
> Plan: [`docs/attribution-stage-plan.md`](../../attribution-stage-plan.md).
> Every documented case where a JTS measurement instrument shipped a number or
> a verdict that misled — with the mechanism of the lie and its disposition.
> Read-only sweep, 2026-07-29. Every row cites a source; no row without one.

## How to read this

**Mechanism of the lie** is a closed vocabulary, chosen so WO-4's detectors and
WO-5's honesty rewires can be scoped by class:

| class | the instrument was wrong because… |
|---|---|
| `unit` | the quantity computed is not the quantity named (PSD vs power, RMS vs peak, response vs correction) |
| `frame` | the number is right but the reference it is expressed against is wrong (band, anchor, axis, geometry, level frame) |
| `model` | it grades against a model that reproduces, omits, or mis-realizes the defect |
| `decimation` | resolution/coverage of the persisted grid destroys the feature being judged |
| `label` | the data is right and the name on it is wrong |
| `gate` | a guard was structurally unreachable, mis-calibrated, or fired on evidence it never observed |
| `coverage` | the instrument is shipped but dead — never runs, or never sees the case it was built for |
| `routing` | the finding was computed correctly and then reached no decision or the wrong one |
| `provenance` | the artifact does not describe its own contents |

**Status** is the disposition as of 2026-07-29. `NEW` marks findings this
retrospective produced that are not yet on an issue.

**Two vocabulary limits are enforced throughout** (inherited from the
adversarial review of the attribution plan, 2026-07-29):

- *Position-invariance within one session is corroborating evidence, never a
  source-vs-room classification.* The shipped detector's own docstring
  (`jasper/audio_measurement/interference_nulls.py`, "What
  `position_invariant` does and does not claim") states that
  position-invariance within one session is equally consistent with an origin
  that travels with the speaker **and** with a room path that did not change
  while the session ran — S0 separated the two only by physically moving the
  speaker. Rows here say "present at N/M positions within one session" and
  never "source-fixed" unless the speaker was physically relocated.
- *Harmonic/distortion numbers are labelled by capture instrument.* A
  consumer-tier or phone mic contributes its own AGC and harmonic floor, so
  any such number is instrument-bounded (see row 32).

## Cross-cutting patterns

Counting the 33 rows above by their primary mechanism:

| class | rows | note |
|---|---:|---|
| `frame` | 10 | **The dominant failure mode.** Right number, wrong reference (3, 4, 5a, 5d, 7, 16, 18, 20, 25, 28). Two of them trace to *one* geometric fact — the tweeter sweep starts at Fc, so the shared analysis band is `[Fc, 2Fc]` instead of `[Fc/2, 2Fc]` (rows 7, 16; #1654 shelved the fix) |
| `routing` | 6 | A verdict was computed correctly and then reached nobody, or reached the wrong decision (5e, 13, 19, 22, 30, 33). **Three of these are "the instrument was right and nothing listened."** |
| `gate` | 6 | Guards structurally unreachable (14), mis-calibrated for the regime (11, 23, 29), ungated on their own preconditions (12), or watching the wrong counter (21) |
| `model` | 5 | Grading against a model that reproduces or mis-realizes the defect (5b, 6, 10, 17, 24) |
| `unit` | 4 | Rows 1 and 2 are the same defect at two scales; 5c is a sign convention; 32 is a cross-instrument disagreement |
| `label` | 3 | Wrong name on right data (9, 20, 27) |
| `coverage` | 2 | Shipped instruments that never run (15, 26) |
| `decimation` | 1 | (8) |
| `provenance` | 1 | (31) |

Three observations the plan should absorb:

1. **`frame` errors dominate, and they are systematically invisible to
   self-comparison.** Every one of rows 4, 5a, 5d, 7, 16, 28 is a case where
   the instrument compared the speaker to *itself* through a shifted reference
   and passed. This is the strongest possible argument for the plan's
   `measure_differently` fix class being a first-class routing target rather
   than an escape hatch.

2. **Six rows are not measurement errors at all — they are routing failures.**
   The flat-spec gauge in row 5e measured a −7.21 dB defect correctly and
   auto-apply fired two seconds later; the room-line acceptance in row 32 read
   its own "remeasure first" recommendation and accepted. Findings as
   first-class persisted artifacts (§3.1 of the plan) is the right structural
   answer, but only if something *gates* on them.

3. **The corpus's own honesty machinery is uneven in a specific way**: the
   numeric layer is excellent (Parseval-exact levels, ε in ppm, τ confirmed
   three ways, write-once evidence), and the *naming and framing* layer is
   weak (32/45 sidecars mislabeled, 1-artifact manifests, a graded band that
   excludes the feature under investigation, a chart legend that blames the
   wrong cause). Attribution is a naming problem. That is the layer this stage
   has to fix.

## Instruments that refused correctly — the counter-examples

Worth recording so the plan does not over-index on distrust:

- **The two-path inversion gate** returned `NO-GO` against its own
  pre-registered threshold (worst-case 4.84 dB vs a 1.0 dB pass bar), stated
  that its hyperparameters were chosen by an oracle and therefore that every
  number is an upper bound, and shelved the method
  (`flat-linearization-20260725/inversion-prototype/GATE-REPORT.md`).
- **The write-once evidence store** rejected the duplicate cloud artifact in
  row 30 and preserved the first (#1872).
- **The E0 experiment** ruled out "is this a regression from the commit we
  happened to run on?" with a full diff of the alignment math before trusting
  its own result (`RESULTS.md`, "Build sanity").
- **PR #1845** shipped a provenance marker (`band_snr_scale="band_power_v2"`)
  rather than silently moving 12 dB of persisted numbers, and refused to bump
  the schema version because the *shape* had not changed.
