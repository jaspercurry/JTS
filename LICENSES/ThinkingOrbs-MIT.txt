thinking-orbs
https://github.com/Jakubantalik/thinking-orbs

JTS vendors a port of this project's rendering engine as
deploy/assets/shared/js/orbs.js. The draw math in that file is upstream's
work, transcribed from src/engine/*.ts and src/presets.ts; the TypeScript
annotations were stripped, the ES modules flattened into one file, and the
grayscale ink ramp was replaced by a two-token CSS ramp (see the file header
for the full list of changes). Preserve this notice with any redistributed
image or bundle that ships the JTS management web assets.
